
# Graded Classes — Landing Page (Vue 3 + Vite)

A professional, responsive landing page for **Graded Classes**, matching the Poppins typography and the color palette:

- Primary `#006B61`
- Accent `#FEB85C`
- Mint `#1DC9BA`
- Cream `#F9DCCF`
- Gray-100 `#EAECF0`
- Ink `#101828`

## Quick Start

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Replace placeholder images in `src/components` with your assets and update content as needed.
